# Практическая работа №1. API, парсинг HTML и RegEx

Дисциплина: «Программные средства сбора, консолидации и аналитики данных». Вариант 27.

В работе собраны данные через открытый API и со статического сайта, выполнены очистка, анализ и визуализация. Анализируются цены ноутбуков по брендам и зарплатные предложения менеджеров по закупкам.

Источники: [API «Работа России»](https://trudvsem.ru/opendata/api) и [учебный каталог Web Scraper](https://webscraper.io/test-sites/e-commerce/allinone/computers/laptops). Получено 146 вакансий и 117 карточек ноутбуков. Учебные цены не описывают текущий рынок техники.

Ноутбук `ПР1_вариант27.ipynb` содержит код, результаты выполнения и выводы. В папке `results` находятся четыре графика, итоговые показатели и статистика цен по брендам.
